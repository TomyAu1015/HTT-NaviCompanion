【放课后茶会 · 轻音音乐库使用与文件导入说明】

本音乐库为独立音乐系统，与导航/测速/伴侣播报音频完全分离。

一、三种导入《轻音音乐.7z》音频的方式：
方式 1：iOS「文件」App 直接放入（最推荐，随时随地可用）
  1. 在电脑或手机上使用解压工具（如 iZip、7zipper 或电脑端 7-Zip）解压 Google 云端硬盘中的《轻音音乐.7z》。
  2. 打开手机自带「文件」App -> 浏览 ->「我的 iPhone」。
  3. 找到「放课后茶会伴侣」目录（App 已开启 iTunes / Files 共享权限）。
  4. 打开里面的「Music」文件夹，将解压后的 mp3 / flac / m4a 文件直接粘贴进去。
  5. 打开 App 进入「音乐馆」，点击刷新或进入即可秒级加载播放！

方式 2：App 内「+ 导入音乐」直接选取
  1. 打开 App 进入右上角「音乐馆」。
  2. 点击右上角「导入音乐」按钮。
  3. 在弹出的系统文件选择器中，直接多选解压后的轻音歌曲，App 将自动复制并载入曲库！

方式 3：随 App 源码一起编译打包
  在打包或上传 GitHub 编译前，直接将解压出的轻音音频文件放入此「Music/」目录下即可随工程一起编译打包进 IPA。

二、与导航音频独立并支持 Auto-Ducking 自动避让：
  - 音乐库拥有独立音量控制与播放队列，不占用导航音频通道。
  - 开启「避让开」时，当出现车速超速、前方转弯或角色主动搭话时，音乐音量会自动平滑轻微压低（降至 25%），播报完成后自动恢复原音量，体验极佳！
